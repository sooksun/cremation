# สเปกการ Upgrade ระบบ - กุมภาพันธ์ 2568

## 1. ทะเบียนสมาชิกสมาคมผู้ประกอบวิชาชีพ

**สมาคม:** สมาคมผู้ประกอบวิชาชีพผู้บริหาร ครู และบุคลากรทางการศึกษา อำเภอแม่ฟ้าหลวง

**ความสัมพันธ์:** รายชื่อสมาชิกฌาปนกิจสงเคราะห์ข้าราชการครูและบุคลากรทางการศึกษา อำเภอแม่ฟ้าหลวง ทุกคนเป็นสมาชิกของสมาคมนี้

### ฟีเจอร์ที่เพิ่ม
- **Model:** AssociationMember (1:1 กับ Member)
  - associationMemberNo: เลขสมาชิกสมาคม
  - position: ตำแหน่งในสมาคม
  - associationJoinDate: วันที่เป็นสมาชิกสมาคม
  - notes: หมายเหตุ
- **API CRUD:** GET, PATCH สำหรับข้อมูลสมาชิกสมาคม
- **หน้าจอ:** รายการสมาชิกสมาคม, แก้ไขข้อมูลสมาชิกสมาคม

### การสร้างสมาชิกใหม่
- การสร้าง Member ผ่านทะเบียนสมาชิกฌาปนกิจ = สมาชิกสมาคมโดยอัตโนมัติ
- สามารถแก้ไขข้อมูลเพิ่มเติมเฉพาะสมาคมได้ที่หน้าทะเบียนสมาชิกสมาคม

## 2. Dashboard สรุปข้อมูลสมาชิกรายบุคคล

**หน้าที่มีอยู่:** `/members/[id]/profile` - หน้าโปรไฟล์สมาชิก

**การปรับปรุง:**
- แสดงสรุปข้อมูล: อายุสมาชิก, ยอดชำระรวม, อัตราการชำระ, สิทธิประโยชน์ที่ได้รับ
- กราฟประวัติการชำระเงินสงเคราะห์
- รายการค้างชำระ (Arrears)
- ประวัติการรับเงินสงเคราะห์ (Death Claims)
- เพิ่มลิงก์เข้าถึงจากเมนูและรายการสมาชิก

## 3. ข้อมูลจาก doc/

โฟลเดอร์ `doc/` ใช้สำหรับ:
- เก็บสเปกและเอกสารอ้างอิงการพัฒนา
- ไฟล์ CSV/Excel สำหรับ import ข้อมูล (ถ้ามี)
- เอกสารมติคณะกรรมการหรืออัตราเงินช่วยเหลือ

**ไฟล์ใน doc/:**
- `UPGRADE_SPEC.md` - สเปกการ upgrade นี้
- `ASSOCIATION_MEMBER_SPEC.md` - รายละเอียด model และ API สมาชิกสมาคม
- `EXCEL_IMPORT_README.md` - คู่มือการแปลง Excel เป็น migration
- `ANALYSIS_DOC_VS_SYSTEM.md` - การวิเคราะห์เปรียบเทียบ doc กับระบบปัจจุบัน
