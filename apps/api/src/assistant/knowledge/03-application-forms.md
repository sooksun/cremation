# ใบสมัครสมาชิกฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวง

> แหล่งที่มา: doc/ref1-1.pdf (สมาชิกสามัญ), doc/ref1-2.pdf (สมาชิกสมทบ)

ทั้งสองแบบฟอร์มมีโครงสร้างและช่องกรอกข้อมูลเหมือนกันทุกประการ ต่างกันเฉพาะชื่อหัวแบบฟอร์ม
กลุ่มเป้าหมาย และข้อความรับรอง 2 จุด (ระบุไว้ในแต่ละหัวข้อย่อยด้านล่าง)

## ใบสมัครสมาชิกสามัญ

**หัวแบบฟอร์ม:** ใบสมัครขอเข้าเป็นสมาชิกสามัญฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวง
(ข้าราชการครู, ลูกจ้างประจำ)

**ช่องข้อมูลบนหัวแบบฟอร์ม**

- เลขทะเบียนสมาชิกอันดับที่ ..... เป็นสมาชิกเมื่อ .....
- ส่วนราชการ .....
- วันที่ ..... เดือน ..... พ.ศ. .....

**ข้อมูลผู้สมัคร**

- ชื่อ-สกุลผู้สมัคร, เกิด (ว.ด.ป.), อายุ (ปี)
- เลขประจำตัวประชาชน (13 หลัก, มีช่องกรอกทีละหลัก)
- ที่อยู่ตามทะเบียนราษฎร: บ้านเลขที่, หมู่ที่, ถนน, ซอย, ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์, เบอร์โทร
- สถานภาพ: เป็นโสด / มีคู่สมรส (ระบุชื่อคู่สมรส)
- ที่อยู่ที่สามารถติดต่อได้: บ้านเลขที่, หมู่ที่, ถนน, ซอย, ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์, โทร

**รายชื่อบุคคลที่มีความเกี่ยวข้องทางสายเลือด/ตามกฎหมาย (บิดา/มารดา/สามี/ภรรยา/บุตร/ธิดา)**

รายการ 1–7 ช่อง แต่ละรายการกรอก: ชื่อ-สกุล, เกี่ยวข้องเป็น (ความสัมพันธ์)

**ผู้รับเงินสงเคราะห์ศพ (เรียงตามลำดับ)**

รายการ 1–3 ช่อง แต่ละรายการกรอก:

- ชื่อ-สกุล, เกี่ยวข้องเป็น (ความสัมพันธ์)
- เลขประจำตัวประชาชน
- ที่อยู่: บ้านเลขที่, หมู่ที่, ถนน, ซอย, ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์, เบอร์โทร
- บุคคลที่สามารถติดต่อได้ + เบอร์โทร

**ลายเซ็นผู้สมัคร**

(ลงชื่อ) ..... ผู้สมัคร / วันที่ .....

**คำรับรองของผู้บังคับบัญชา**

ข้าพเจ้าผู้มีนามข้างท้ายนี้ขอรับรองว่า

1. ผู้สมัครรายนี้เป็นผู้มีคุณสมบัติตามระเบียบว่าด้วยการเป็นสมาชิกของฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวง
2. เป็นผู้มีสิทธิสมัครเข้าเป็นสมาชิกสามัญของกองทุนฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวงได้
3. ผู้สมัครตกลงให้เก็บเงินสงเคราะห์รายกรณีเสียชีวิตของสมาชิกสามัญ และสมาชิกสมทบ บิดา มารดา
   และบุตร ธิดา สายตรงของสมาชิก ตามระเบียบข้อบังคับของกองทุนฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวง
4. ข้อความทั้งหมดตามที่ผู้สมัครได้กล่าวไว้นั้นเป็นความจริงทุกประการ และผู้สมัครได้ลงชื่อต่อหน้าคณะกรรมการ

ผู้บังคับบัญชารับรอง ..... / ตำแหน่ง ..... (ผู้อำนวยการโรงเรียน หรือรักษาการแทนในตำแหน่ง)

**ตรวจสอบถูกต้องแล้ว**

## ใบสมัครสมาชิกสมทบ

**หัวแบบฟอร์ม:** ใบสมัครขอเข้าเป็นสมาชิกสมทบฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวง
(ครูอัตราจ้าง, ครูธุรการ, ลูกจ้างของหน่วยงาน, ลูกจ้างของโรงเรียน)

โครงสร้างช่องกรอกข้อมูลเหมือนกับใบสมัครสมาชิกสามัญทุกประการ (เลขทะเบียนสมาชิก, ส่วนราชการ,
วันที่สมัคร, ข้อมูลผู้สมัคร, เลขประจำตัวประชาชน, ที่อยู่ตามทะเบียนราษฎร, สถานภาพสมรส, ที่อยู่ที่ติดต่อได้,
รายชื่อบุคคลที่มีความเกี่ยวข้องทางสายเลือด/ตามกฎหมาย 1–7 รายการ, ผู้รับเงินสงเคราะห์ศพเรียงตามลำดับ
1–3 รายการพร้อมเลขประจำตัวประชาชนและที่อยู่, ลายเซ็นผู้สมัคร)

**คำรับรองของผู้บังคับบัญชา** เหมือนกับแบบสมาชิกสามัญ ยกเว้นข้อ 2 ซึ่งเปลี่ยนเป็น:

1. ผู้สมัครรายนี้เป็นผู้มีคุณสมบัติตามระเบียบว่าด้วยการเป็นสมาชิกของฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวง
2. เป็นผู้มีสิทธิสมัครเข้าเป็นสมาชิกสมทบฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวงได้
3. ผู้สมัครตกลงให้เก็บเงินสงเคราะห์รายกรณีเสียชีวิตของสมาชิกสามัญ และสมาชิกสมทบ บิดา มารดา
   และบุตร ธิดา สายตรงของสมาชิก ตามระเบียบข้อบังคับของกองทุนฌาปนกิจสงเคราะห์ครูแม่ฟ้าหลวง
4. ข้อความทั้งหมดตามที่ผู้สมัครได้กล่าวไว้นั้นเป็นความจริงทุกประการ และผู้สมัครได้ลงชื่อต่อหน้าคณะกรรมการ
