# สารบัญเอกสารและความเชื่อมโยง (อ่านส่วนนี้ก่อนตอบทุกครั้ง)

ฐานความรู้นี้มีเอกสาร **2 ฉบับหลัก คนละองค์กร** และ **1 ชุดแบบฟอร์ม** เลขข้อของสองฉบับซ้ำกันได้
จึงต้องระบุชื่อเอกสารคู่กับเลขข้อเสมอ

| เอกสาร | ครอบคลุมเรื่อง | เรียกอ้างอิงว่า |
|---|---|---|
| ข้อบังคับสมาคมผู้ประกอบวิชาชีพผู้บริหาร ครู และบุคลากรทางการศึกษา อำเภอแม่ฟ้าหลวง พ.ศ. 2566 (ข้อ 1–38) | ตัวสมาคมฯ: ชื่อ/ตราสัญลักษณ์/ที่ตั้ง วัตถุประสงค์ ประเภทสมาชิก ค่าบำรุง สิทธิหน้าที่ คณะกรรมการ การประชุมใหญ่ การเงินและทรัพย์สิน การแก้ข้อบังคับ การเลิกสมาคม | "ข้อบังคับสมาคมฯ ข้อที่ N" |
| ระเบียบว่าด้วยฌาปนกิจสงเคราะห์ข้าราชการครูและบุคลากรทางการศึกษา อำเภอแม่ฟ้าหลวง พ.ศ. 2568 (ข้อ 1–21) | กองทุนฌาปนกิจ: สมาชิกภาพสามัญ/สมทบ คณะกรรมการดำเนินงาน การหักเงินสงเคราะห์ศพ ผู้ได้รับความคุ้มครอง การขอรับเงิน ลำดับผู้รับเงิน | "ระเบียบฌาปนกิจฯ ข้อ N" |
| ใบสมัครสมาชิกฌาปนกิจ (สามัญ / สมทบ) | ช่องข้อมูลในแบบฟอร์ม ผู้รับผลประโยชน์ คำรับรองของผู้บังคับบัญชา | "แบบฟอร์มใบสมัคร" |

## สองเรื่องนี้เกี่ยวข้องกันอย่างไร

- **กองทุนฌาปนกิจอยู่ภายใต้สมาคมฯ** — ระเบียบฌาปนกิจฯ ออกโดยคณะกรรมการดำเนินงานฌาปนกิจสงเคราะห์
  ในสังกัดสมาคมฯ
- **นายกสมาคมฯ เป็นประธานกรรมการฌาปนกิจโดยตำแหน่ง** (ระเบียบฌาปนกิจฯ ข้อ 10.1) และเป็นผู้รักษาการ
  ตามระเบียบ (ข้อ 5) รวมทั้งเป็นผู้วินิจฉัยชี้ขาดเมื่อมีปัญหาการใช้ระเบียบ (ข้อ 21)
- **อุปนายกสมาคมฯ เป็นรองประธานกรรมการฌาปนกิจ** (ระเบียบฌาปนกิจฯ ข้อ 10.2)
  และผู้บริหารโรงเรียนทุกโรงเป็นกรรมการ (ข้อ 10.3)
- **เงินไหลข้ามกันได้ทางเดียว** — เงินที่หักเข้ากองทุนฌาปนกิจร้อยละ 10 (ระเบียบฌาปนกิจฯ ข้อ 13.5.2,
  ข้อ 16) ใช้เป็นค่าดำเนินงานของ ฌ.ป.ส.ค. **และใช้ในกิจกรรมของสมาคมฯ ได้** โดยต้องได้รับอนุมัติ
  เบิกจ่ายเป็นลายลักษณ์อักษรทุกครั้ง (ข้อ 13.6)
- **งานศพใช้ชื่อสมาคมฯ** — พวงหรีดและการร่วมเป็นเจ้าภาพสวดอภิธรรมทำในนามสมาคมฯ
  (ระเบียบฌาปนกิจฯ ข้อ 18.1, 18.2)

## จุดที่คนมักสับสน — ต้องแยกให้ชัด

| ประเด็น | ฝั่งสมาคมฯ | ฝั่งฌาปนกิจ |
|---|---|---|
| ประเภทสมาชิก | 3 ประเภท: สามัญ / กิตติมศักดิ์ / สมทบ (ข้อบังคับสมาคมฯ ข้อ 5) | 2 ประเภท: สามัญ / สมทบ (ระเบียบฌาปนกิจฯ ข้อ 7) |
| เงินที่ต้องจ่าย | ค่าบำรุงสมาคม **ปีละ 100 บาท** ชำระทุกปีในวันครู (ข้อบังคับสมาคมฯ ข้อ 9) | เงินสงเคราะห์ศพ **รายกรณี** สมาชิกตายคนละ 100 บาท ญาติสายตรงตายคนละ 50 บาท (ระเบียบฌาปนกิจฯ ข้อ 13.1, 13.2) |
| การเข้าเป็นสมาชิก | ยื่นต่อนายทะเบียนสมาคมฯ แจ้งผลภายใน 30 วัน (ข้อบังคับสมาคมฯ ข้อ 7) | ข้าราชการครูและลูกจ้างประจำเป็นสมาชิกสามัญ **อัตโนมัติ** ต้องยื่นเอกสารภายใน 30 วัน (ระเบียบฌาปนกิจฯ ข้อ 8) |
| การสิ้นสุดสมาชิกภาพ | ตาย / ลาออก / ขาดคุณสมบัติ / ที่ประชุมใหญ่ลงมติ / ค้างค่าบำรุง 2 ปี (ข้อบังคับสมาคมฯ ข้อ 10) | ตาย / ขาดคุณสมบัติ / เกษียณ (สามัญ) และสมทบที่ไม่ส่งเงิน **ติดต่อกัน 3 ราย** (ระเบียบฌาปนกิจฯ ข้อ 9) |
| ผู้มีอำนาจสั่งจ่าย | นายกสมาคมฯ สั่งจ่ายได้ครั้งละไม่เกิน 5,000 บาท เกินกว่านั้นต้องผ่านคณะกรรมการ (ข้อบังคับสมาคมฯ ข้อ 28) | คณะกรรมการกองทุนเบิกจ่ายค่าสงเคราะห์ศพ ภายในวันที่ 30 ของเดือนที่ได้รับแจ้ง (ระเบียบฌาปนกิจฯ ข้อ 13.3) |

**ข้อควรระวัง**: การลาออกจากสมาคมฯ กับการสิ้นสุดสมาชิกภาพฌาปนกิจเป็นคนละเงื่อนไขกัน อย่าสรุปว่า
พ้นอย่างหนึ่งแล้วพ้นอีกอย่างโดยอัตโนมัติ — ให้ตอบตามเงื่อนไขของแต่ละฉบับแยกกัน

## อภิธานศัพท์ (คำพูดชาวบ้าน → ศัพท์ในเอกสาร)

- "ค่าหัว", "เก็บศพ", "เก็บรายศพ", "ลงขัน" → **เงินสงเคราะห์ศพรายกรณี** (ระเบียบฌาปนกิจฯ ข้อ 13.1/13.2)
- "ค่าบำรุง", "ค่าสมาชิกรายปี" → **ค่าบำรุงสมาคม ปีละ 100 บาท** (ข้อบังคับสมาคมฯ ข้อ 9)
- "เงินฌาปนกิจ", "เงินช่วยงานศพ", "เงินสงเคราะห์" → เงินที่จ่ายให้ผู้มีสิทธิ **ร้อยละ 90** ของยอดที่เก็บได้
  (ระเบียบฌาปนกิจฯ ข้อ 16)
- "หักเข้ากองทุน", "ค่าบริหาร" → ส่วน **ร้อยละ 10** ที่หักเข้าบัญชีกองทุน (ระเบียบฌาปนกิจฯ ข้อ 13.5.2, ข้อ 16)
- "ตกเบิก", "ค้างส่ง", "ค้างจ่าย" → เงินสงเคราะห์ที่ยังไม่ได้ชำระ
- "ผู้รับผลประโยชน์", "คนรับเงิน" → ผู้ที่สมาชิกระบุไว้ในใบสมัคร ตามลำดับใน ระเบียบฌาปนกิจฯ ข้อ 19
- "คนในความคุ้มครอง", "ญาติสายตรง" → คู่สมรสตามกฎหมาย บิดา-มารดา บุตร-ธิดา ของสมาชิก
  (ระเบียบฌาปนกิจฯ ข้อ 14)
- "พ้นสภาพ", "ตัดชื่อออก" → สมาชิกภาพสิ้นสุด (ข้อบังคับสมาคมฯ ข้อ 10 หรือ ระเบียบฌาปนกิจฯ ข้อ 9
  แล้วแต่ว่าถามถึงองค์กรใด)

## วิธีคิดเงินสงเคราะห์ (ระเบียบฌาปนกิจฯ ข้อ 13, 16)

```
ยอดเก็บรวม = จำนวนสมาชิกที่ร่วมจ่าย × อัตราต่อคน
              (สมาชิกเสียชีวิต 100 บาท/คน · ญาติสายตรงเสียชีวิต 50 บาท/คน)
หักเข้ากองทุน  = ยอดเก็บรวม × 10%
จ่ายผู้มีสิทธิ  = ยอดเก็บรวม × 90%
```

หากคณะกรรมการกำหนดยอดต่อศพไว้แบบตายตัว ให้ใช้ยอดนั้นเป็นตัวตั้งแทนการคูณจำนวนสมาชิก แล้วแบ่ง
90/10 เหมือนเดิม
